# combat-simulator
combat simulator between warrior and a couple of bad guys
The player will face a string of enemies and a boss.
Fights will be fought each turn having 2 actions: 
- attack, defend, use consumables
- attacks and defends will have a direction(top, right, bottom, left)
consumables will be used from an inventory
after defeating an enemy, the player will get some loot(gold, potions)
gold can be used in a shop
